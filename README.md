# Dreamweaver starter

A dependency-free Node 24 bot for BlockWarriors Dreamweaver. Use this repository as a template, change `bot.mjs`, and link your copy in the Dreamweaver workspace. Commit and tag a revision; import that tag to archive an immutable submission.

The bot reads JSON lines from stdin and writes JSON action envelopes to stdout. Diagnostics go to stderr. It gathers crystals, delivers to the beacon, and dashes away from hazards. Replace the strategy freely.

Read AGENTS.md for the wire contract. Rules, infrastructure, and SDK live in `project-blockwarriors/blockwarriors-dreamweaver-cmd`. This is a prototype, not a finalized competition ruleset.
